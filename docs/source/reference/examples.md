# Examples

Practical examples for common SMV use cases.

## Project Organization
```bash
smv snake ./src EXT:rs -rp
```

## File Cleanup
```bash
smv rm . EXT:tmp EXT:log -rp
```

## Batch Renaming
```bash
smv CHANGE: "IMG_" INTO "" ~/Photos -p
```
